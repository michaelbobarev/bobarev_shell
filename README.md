# 🛠️ Universal Debian / Ubuntu / Armbian Server & PC Setup Script

Универсальный интерактивный Bash-скрипт для автоопределения оборудования, базовой настройки, повышения безопасности и оптимизации VPS-серверов, десктопных ПК и одноплатных компьютеров (SBC).
## 🚀 Быстрый запуск в одну команду

Запустите от имени `root` в терминале вашего сервера или ПК:

```bash
curl -sSL https://raw.githubusercontent.com/michaelbobarev/bobarev_shell/main/bobarev_shell.sh | bash
```
