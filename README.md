🌐 Базовая система и сервер

- Часовой пояс - установка актуального системного часового пояса с точной синхронизациеи времени.
- Имя хоста — автоматическая установка имени системы с корректной привязкой в /etc/hosts.
- Обновление системы - апдейт пакетов, активация unattended-upgrades и предотвращение конфликтов ZRAM.
- Создание и настройка пользователя — создание sudo-пользователя с паролем и опциональным NOPASSWD.
- Настройка SSH-ключей — привязка публичных ключей с автоматическим выставлением прав на .ssh/authorized keys.
- Безопасность SSH — смена порта, блокировка root пользователя, защита от замусоривания и возможность ограничения доступа строго через сеть Tailscale.
- Защита ядра и сети — подгрузка BBR, оптимизация FQ, TCP FastOpen, RFC1337 и защита sysctl от спуфинга и ICMP-атак.
- Межсетевой экран UFW — конфигурация файрвола, защита портов и изоляция SSH внутри туннеля Tailscale.
- Блокировка пароля root — полная блокировка записи root при наличии альтернативного sudo-пользователя.
- Tailscale, GRO и Web UI — авто-установка меш-сети, анонс Exit-Node/LAN-подсетей, стелс-режим, GRO-ускорение UDP и веб-интерфейс управления Tailscale Web.
- Отключение системного логирования — перевод journald в режим Storage=none, маскирование rsyslog/auditd и очистка /var/log для сохранения ресурса накопителей.
- Оптимизация RAM и накопителей — защита ресурса Flash (MicroSD/eMMC/SSD) через noatime, commit=120, выравнивание dirty_writeback_centisecs и перенос временных директорий в tmpfs.
- Управление файлом подкачки — интерактивное создание, изменение размера или полное удаление файла SWAP.

🖥️ PC, роутер и диагностика

- РС-утилиты и автозапуск — быстрая установка трей-апплетов сети, звука, bluetooth и батареи для графических оболочек.
- Программный сброс HDMI — автоматический перезапуск видеовыхода в LightDM/xrandr для устранения проблем с внешними мониторами.
- Диагностика времени загрузки — детальный анализ старта systemd c сохранением текстового отчёта и SVG-графика загрузки.
- Полный аудит настроек сервера — интеллектуальная проверка системы, параметров ядра, безопасности SSH/UFW, логирования и сети Tailscale.
- Одноплатный компьютер как роутер — превращение SBC (NanoPi/Raspberry) в LAN-шлюз c DHCP (dnsmasq), DNS, MSS Clamping, защитой от конфликта подсетей и роутингом через Tailscale Exit-Node.
