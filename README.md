🌐 Базовая система и сервер

- Часовой пояс - точная синхронизация системного времени и установка актуального часового пояса.
- Имя хоста - автоматическая установка понятного имени хоста и правильная привязка к /etc/hosts.
- Обновление системы - обновление пакетов, настройка автоматических обновлений и предотвращение конфликтов zRAM.
- Создание и настройка пользователя — создание sudo-пользователя, установка пароля и опциональная настройка NOPASSWD.
- Настройка SSH-ключей - привязка публичных SSH-ключей с безопасным выставлением прав на .ssh/authorized_keys.
- Безопасность SSH - смена стандартного порта, отключение входа для root и проверка портов перед перезапуском.
- Защита ядра и сети - применение параметров sysctl для защиты от сетевых атак, спуфинга и лишних ответов на ІСМР.
- Межсетевой экран UFW - конфигурация файрвола с закрытием лишних портов и изоляцией SSH внутри сети Tailscale.
- Блокировка пароля root - защита от подбора паролей путем полной блокировки записи root при наличии альтернативного sudo-пользователя.
- Tailscale и GRO-оптимизация - развертывание меш-сети Tailscale и оптимизация для ускорения UDP-трафика.
- Отключение системного логирования - остановка лишней записи логов на диск для сбережения ресурса для множества накопителей.
- Оптимизация RAM и накопителей - настройка swappiness, перенос / tmp и /var/tmp в tmpfs, а также монтирование дисков с флагом noatime.
- Управление файлом подкачки - интерактивное создание, изменение размера или полное удаление файла SWAP.

🖥️ PC, роутер и диагностика

- PC-утилиты и автозапуск — быстрая установка трей-апплетов сети, звука, bluetooth и батареи для графической оболочки XFCE.
- Программный сброс HDMI — автоматический перезапуск видеовыхода для устранения проблем с внешними мониторами.
- Диагностика времени загрузки — детальный анализ старта системы и сохранением отчетов, графика в формате svg.
- Полный аудит настроек сервера — сводный отчет о текущем состоянии часового пояса, фаейрвола, ядра и обновлений.
- Одноплатный компьютер как роутер — превращение SBC в LAN-шлюз с поддержкой DHCP, DNS, MSS Clamping и роутингом через Tailscale Exit-Node.
